# 🕵️ NoirBoard — Стол детектива и Стена связи улик для SillyTavern

**NoirBoard** — это комплексное расширение для детективных, триллерных, киберпанк и мистических ролевых игр в **SillyTavern**. Оно добавляет интерактивное рабочее место следователя с двумя связанными разделами: **Столом детектива** и **Стеной связи улик (Mind Board)**.

## ✨ Основные возможности

### 1. 🗄️ Стол детектива (Detective's Desk)
На столе хранятся и раскладываются все добытые в ходе ролевой игры материалы. Каждый предмет можно взять в руки, почитать и детально осмотреть:
- **Личные дела и Секретные досье (`dossier`)** — два аутентичных макета:
  - *Классическая папка с фото на металлической скрепке*, анкетой (внешность, характер, деятельность, связи, история), круглой печатью организации и штампом `CONFIDENTIAL`.
  - *Строгий бланк «СЕКРЕТНОЕ ДОСЬЕ»* (документ ограниченного доступа с таблицей параметров, фото Анфас/Профиль и нумерованными блоками: 1. Особые приметы, 2. Характеристика, 3. Подготовка и навыки, 4. Архивная справка).
- **Газеты и вырезки прессы (`newspaper`)** — многоколоночная газетная вёрстка с заголовками передовиц, датой выпуска, Ч/Б репортажным снимком и именем корреспондента.
- **Дактилоскопические карты (`fingerprints`)** — отпечатки пальцев (завитки, петли, дуги), полные оттиски ладоней с линиями сгибов и следы подошв обуви с отметками точек совпадения (минуций) и процентом совпадения.
- **Зип-пакеты с вещественными уликами (`evidence_bag`)** — прозрачный пластиковый пакет с красной пломбой, жёлтой биркой `Evidence #12A` и протоколом лабораторной экспертизы.
- **Фотографии с места преступления (`photo`)** — снимки Polaroid с таймстампом (`1998/09/14`), возможностью сгенерировать изображение через `/sd` и рукописными заметками на обороте.
- **Карты и схемы преступления (`map`)** — топографические и дорожные схемы с красными кругами-отметками, маршрутами и координатами (`34.0522 N, -118.2437 W`).
- **Письма и записки на печатной машинке (`letter`)** — состаренная бумага со следами сгибов, пятнами и машинописным шрифтом.
- **Дневники и полевые журналы (`diary`)** — разворот старой тетради на четырёх кольцах с приколотыми на скрепку фотокарточками и заметками.
- **Официальные отчёты и экспертизы (`report`)** — бланки судмедэкспертизы, баллистики и полицейских рапортов.
- **Оккультные манускрипты и артефакты (`occult`)** — страницы бестиариев, зарисовки мистических печатей и паранормальные улики.

### 2. 📌 Стена связи улик (Evidence Wall)
- Любой документ со стола или отдельную зацепку внутри документа можно **закрепить булавкой на Стене связей**.
- Карточки можно свободно **перетаскивать (Drag & Drop)** по пробковой доске.
- **Натяжение цветных нитей:** связывайте улики между собой нитками разных цветов (красная — прямая улика/подозреваемый, жёлтая — гипотеза/вопрос, синяя — алиби/хронология, зелёная — мотив/финансы, фиолетовая — мистика) и подписывайте каждую связь.
- **🧠 Дедукция ИИ по стене:** нажмите кнопку анализа, и модель изучит закреплённые вами улики и протянутые нитки, чтобы выдать дедуктивную сводку, найти противоречия и подсказать следующую зацепку.

### 3. 🔍 Интерактивная лупа и осмотр деталей
- В окне просмотра доступен режим **«Лупа»**: визуальная линза усиливает контраст, а блок `hiddenDetail` подсвечивается. Настоящее оптическое увеличение пока не реализовано.

### 4. 🎭 Три режима работы
1. **Стандарт (Классический стол / Нуар)** — тёмное дерево, бумажные папки, печатная машинка и пробковая доска.
2. **Современный (Кибер / OSINT-терминал)** — интерфейс электронной базы данных со встроенным поисковым терминалом **«Поискать в сети / Пробить по базе данных»** (вы можете ввести любое имя, номер машины, адрес или улику и получить криминалистическую выдачу, которую можно сохранить в дело).
3. **Сверхъестественное / Мистика** — стол исследователя паранормального с генерацией оккультных улик, бестиариев, дневников охотника и проклятых артефактов.

### 5. 🔒 Безопасная работа с профилями подключения
- Для текста можно выбрать профиль Connection Manager SillyTavern. При его ошибке расширение показывает сообщение и не переключается на другую модель.
- Изображения создаются штатной командой `/sd` с настройками Image Generation в SillyTavern. Независимый выбор пресета изображений пока не реализован; список текстовых профилей для изображений удалён как неработающий.
- **Безопасность:** расширение читает только публичные имена и ID профилей через штатный контекст SillyTavern и **никогда не просматривает, не запрашивает и не сохраняет ваши API-ключи**.

## 📦 Установка в SillyTavern

1. Откройте SillyTavern и перейдите во вкладку **Extensions (Расширения)** в верхней панели.
2. Нажмите **Install Extension (Установить расширение)**.
3. Вставьте ссылку на GitHub-репозиторий:
   ```text
   https://github.com/Ayrissa/NoirBoard
   ```
4. Нажмите **Install** и обновите страницу браузера.

## 🚀 Как пользоваться

- **Через меню «Волшебной палочки» (🪄):** нажмите на иконку палочки рядом с полем ввода чата и выберите **«NoirBoard — Стол детектива»**.
- **Через слэш-команды:**
  - `/noirboard` или `/detective` — открыть Стол детектива
  - `/noirboard wall` — сразу открыть Стену связи улик
  - `/noirboard settings` — открыть настройки расширения
- **Кнопка «Изучить дело»:** сканирует последние сообщения чата и автоматически создаёт новые материалы расследования на столе.
- **Кнопка «Загрузить демонстрационный набор улик»:** доступна на пустом столе, чтобы сразу протестировать все виды досье, писем, отпечатков, газет, карт и нитей без обращения к API.

## 🗂️ Структура

```text
manifest.json   index.js   style.css   LICENSE   README.md
tests/         scripts/
```

Для установки нужны все три файла: `manifest.json`, `index.js`, `style.css`. Сборка и установка npm-зависимостей не требуются.

## Проверки разработки

Node.js 20+: `npm test` — регрессии CSS, профилей, нормализации данных и шаблонов.

`npm run test:browser` — автономные проверки интерфейса в headless Microsoft Edge на Windows. Другой Chromium-браузер можно указать переменной `NOIRBOARD_BROWSER`. HTML-стенды и скриншоты сохраняются в игнорируемую Git папку `.browser-check`. Стенд не подключается к SillyTavern и не отправляет запросов к ИИ; штатный шрифт иконок SillyTavern в нём не загружается.

## Известные ограничения

- Поиск в современном режиме — генерация вымышленной выдачи по миру РП, не поиск в настоящем интернете.
- Отпечатки и карта без собственного изображения — схематические SVG, не реалистичные криминалистические снимки.
- Проверки интерфейса не заменяют тестирование в SillyTavern с конкретной темой, на настоящем телефоне и с выбранным провайдером генерации.
- Сохраняется прежнее хранилище дел в настройках расширения. Миграция больших архивов и защита фоновой генерации при смене чата требуют отдельного этапа.
